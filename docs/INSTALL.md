# AnomalyStudio 導入マニュアル

AnomalyStudio のインストール、初回の使い方、更新、アンインストールの手順です。上から順に進めてください。

## 0. はじめに確認すること

- **対応している PC**

  | 種類 | 動作確認 |
  |---|---|
  | Windows 10 / 11（x64。ほとんどの Windows PC） | 確認済み |
  | Windows 11（ARM。Surface Pro X、Snapdragon 搭載機など） | 未検証（ビルドのみ） |
  | Mac（Apple シリコン。M1 以降） | 未検証（ビルドのみ） |
  | Mac（Intel） | 未検証（ビルドのみ） |

  「未検証」の種類は、開発側で実機の動作を確かめていません。動かない場合があります。
- **インターネット接続**が必要です。市場データと経済指標を、使うたびに取得します。
- **ディスクの空き**は 2 GB 以上を目安にしてください（アプリ約 400 MB、1 銘柄 1 年分のデータ約 30 MB、分析結果）。
- **管理者の権限**は要りません。自分のユーザーにだけインストールされます。
- **利用条件**: 非商用の利用に限ります。改変・再配布はできません（[LICENSE.md](../LICENSE.md)）。

> [!IMPORTANT]
> このアプリはコード署名をしていません。そのため、インストールの途中で Windows や macOS が「保護しました」「開けません」などの警告を出します。
> 下の手順どおりに許可すれば使えます。警告が出るのは初回のインストールだけで、アプリ内の自動更新では出ません。

## 1. 自分の PC の種類を調べる

**Windows**

1. 「スタート」ボタンを右クリックし、「システム」を選びます。
2. 「デバイスの仕様」の「システムの種類」を見ます。
   - 「x64 ベース プロセッサ」なら **win-x64** です。
   - 「ARM ベース プロセッサ」なら **win-arm64** です。

**Mac**

1. 画面左上の Apple メニュー（りんごのマーク）から「この Mac について」を選びます。
2. 「チップ」または「プロセッサ」の欄を見ます。
   - 「Apple M1」「Apple M2」などなら **osx-arm64** です。
   - 「Intel」なら **osx-x64** です。

## 2. インストーラーをダウンロードする

1. ブラウザーで [Releases](https://github.com/HatchSystem/anomaly-studio-oss/releases) を開きます。
2. いちばん上の版（「Latest」の印が付いたもの）の「Assets」を開きます。
3. 1 で調べた種類のファイルを選んでダウンロードします。

   | 種類 | ダウンロードするファイル |
   |---|---|
   | win-x64 | `HatchSystem.AnomalyStudio-win-x64-Setup.exe` |
   | win-arm64 | `HatchSystem.AnomalyStudio-win-arm64-Setup.exe` |
   | osx-arm64 | `HatchSystem.AnomalyStudio-osx-arm64-Setup.pkg` |
   | osx-x64 | `HatchSystem.AnomalyStudio-osx-x64-Setup.pkg` |

> [!NOTE]
> 名前に `full.nupkg`、`delta.nupkg`、`Portable.zip`、`releases.` が付くファイルは、自動更新用です。ダウンロードは不要です。

**Microsoft Edge で「一般的にダウンロードされていません」と出たとき**

1. ダウンロードの一覧で、そのファイルの「…」（その他の操作）を押します。
2. 「保存」を押します。
3. さらに確認が出たら、「詳細表示」を押してから「保持する」を押します。

## 3. インストールする（Windows）

1. ダウンロードした `…-Setup.exe` をダブルクリックします。
2. 青い画面で「Windows によって PC が保護されました」と出たら、次のように許可します。
   1. 「詳細情報」を押します。
   2. 「アプリ」と「発行元: 不明な発行元」が表示されるので、「実行」を押します。
3. インストールは自動で進み、終わると AnomalyStudio が起動します。
4. デスクトップとスタートメニューに「AnomalyStudio」が追加されます。次からはここから起動します。

> [!WARNING]
> - 「実行」ボタンが出ない場合は、会社などの管理ポリシーで未署名のアプリが禁止されています。管理者に相談してください。
> - ウイルス対策ソフトがインストーラーを止めることがあります。その場合は、このページの Releases から取得したファイルであることを確かめたうえで、ウイルス対策ソフトの画面で許可してください。

## 4. インストールする（Mac）

1. ダウンロードした `…-Setup.pkg` をダブルクリックします。
2. 「"…Setup.pkg" は開けません」（Apple が確認できない、など）と出たら、「完了」または「OK」を押して閉じ、次のように許可します。
   1. Apple メニューから「システム設定」を開きます。
   2. 左の一覧から「プライバシーとセキュリティ」を選びます。
   3. 右側を下へスクロールし、「"…Setup.pkg" は Mac を保護するためにブロックされました」の横の「このまま開く」を押します。
   4. Mac のログインパスワード（または Touch ID）を求められたら入力します。
   5. もう一度確認が出たら「このまま開く」を押します。
3. インストーラーの案内に従って「続ける」「インストール」を押します。
4. 終わったら「アプリケーション」フォルダー（または Launchpad）から AnomalyStudio を開きます。
5. アプリを開くときにも同じ警告が出たら、手順 2 と同じように「プライバシーとセキュリティ」で「このまま開く」を押します。

> [!WARNING]
> - macOS 15（Sequoia）以降では、アプリを右クリックして「開く」を選ぶ方法では許可できません。上の「プライバシーとセキュリティ」の手順を使ってください。
> - 「壊れているため開けません」と出て「このまま開く」が表示されない場合は、アプリを「アプリケーション」フォルダーへ入れたあと、「ターミナル」で次の 1 行を実行してから開き直してください（ダウンロードしたファイルに付く「隔離」の印を外すコマンドです）。
>
>   ```sh
>   xattr -dr com.apple.quarantine /Applications/AnomalyStudio.app
>   ```
> - AI アシストの API キーはキーチェーンに保存します。更新のあとに「キーチェーンにアクセスしようとしています」と聞かれたら、ログインパスワードを入れて「常に許可」を押してください（署名していないため、更新で聞かれ直すことがあります）。

## 5. はじめて使う

1. 左の一覧から「データ抽出設定」（漏斗のアイコン）を開きます。
2. 「分析を実行」を押します。1 年分の 1 分足を取り込み、分析します。1 銘柄あたり 1〜2 分かかります（最初に登録されている 13 銘柄をすべて取り込むと 10〜20 分）。
3. 終わったら「エントリー」や「ダッシュボード」に、分析から選んだエントリーポイントが出ます。

> [!TIP]
> - 使わない銘柄は「設定 › 銘柄」でオフにすると、取込と分析が速くなります。
> - 取り込んだデータは PC に保存され、次からは差分だけを取り込みます。
> - 取込中にネットワークが切れても、その銘柄だけが失敗し、ほかの銘柄は続けます。あとでもう一度「分析を実行」を押してください。

## 6. 更新する

新しい版は自動で届きます。操作は「再起動して更新」を押すだけです。

1. 起動すると、裏で新しい版を確認し、あればダウンロードします。
2. ダウンロードが済むと、画面上部の版の横に「… に更新できます（設定 › アプリの更新）」と出ます。
3. 「設定」を開き、「アプリの更新」の「再起動して更新」を押します。押さなくても、次にアプリを起動したときに更新されます。

> [!NOTE]
> - 取込・分析・バックテストの実行中は「再起動して更新」を押しても再起動しません。終わってから押してください。
> - 取り込んだデータ・分析結果・設定は、更新しても消えません。
> - 更新で分析の計算方法が変わった場合は、「再分析が必要」と表示されます。「分析を実行」で分析し直してください。
> - 自動で確認したくないときは、「設定 › 起動時に更新を確認」をオフにします（「更新を確認」ボタンで手動で確認できます）。

## 7. アンインストールする

**Windows**

1. 「スタート」ボタンを右クリックし、「インストールされているアプリ」を選びます。
2. 一覧の「AnomalyStudio」の「…」を押し、「アンインストール」を押します。

**Mac**

1. AnomalyStudio を終了します。
2. 「アプリケーション」フォルダーの AnomalyStudio をゴミ箱に入れます。

> [!IMPORTANT]
> アンインストールしても、取り込んだデータ・分析結果・設定は残ります（入れ直したときにそのまま使えるように）。完全に消すときは、次のフォルダーも削除してください。
>
> | | フォルダー | 開き方 |
> |---|---|---|
> | Windows | `%LOCALAPPDATA%\AnomalyStudio` | Windows キー + R を押し、`%LOCALAPPDATA%\AnomalyStudio` と入力して Enter |
> | Mac | `~/Library/Application Support/AnomalyStudio` | Finder のメニュー「移動」›「フォルダへ移動」で `~/Library/Application Support/AnomalyStudio` と入力 |
>
> AI アシストの API キーは、Windows は「資格情報マネージャー › Windows 資格情報」の `AnomalyStudio:AiApiKey`、Mac は「キーチェーンアクセス」の `AnomalyStudio:AiApiKey` です。アプリの「設定 › AI アシスト › 削除」でも消せます。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 「分析を実行」で失敗した銘柄がある | 通信が一時的に切れた可能性があります。時間をおいてもう一度押してください |
| 経済指標カレンダーが空になる | 取得元の形式が変わった可能性があります。保存済みの分は表示されます。新しい版を待ってください |
| 起動しない、途中で落ちる | ログを確認してください。Windows は `%LOCALAPPDATA%\AnomalyStudio\logs`、Mac は `~/Library/Application Support/AnomalyStudio/logs` に日別のファイルがあります |
| 更新が届かない | 「設定 › アプリの更新」の「更新を確認」を押し、表示される説明を確認してください。ネットワークの制限で GitHub に接続できないと更新できません |

> [!CAUTION]
> - 市場データ（Dukascopy）と経済指標（GMO クリック証券）は、公式の API ではない方法で取得しています。提供側の変更で取得できなくなることがあります。利用条件は各社のものに従ってください。
> - 分析結果は過去のデータの統計で、将来の成績を保証しません。投資の判断はご自身の責任で行ってください。
