# AnomalyStudio 変更履歴

## v0.2.0（2026-10-11）

### 分析と検証

- 利益効率の順位付けを、旧レポートに合わせて 30・90・365 日の利益効率の平均を基準にしました。日をまたぐ取引の扱いは現行仕様を維持しています。
- 「利益効率（短期30日）」「利益効率（中期90日）」「利益効率（長期365日）」を追加しました。初期状態では無効です。単一銘柄・複合・ウォークフォワードで同じ期間の指標を使用します。品質除外は既存の基準を維持します。
- 最適化確認とウォークフォワードの銘柄・モード・検証期間・評価サイクルを、画面ごとに保存します。時間帯・上位件数・曜日は共通設定です。保存済みの日付は翌日も自動で移動しません。

最適化確認は最新のポイントを検証期間の各日に適用し、評価サイクルで集計します。ウォークフォワードは各基準日より前のデータで選び直します。利益効率の評価期間と、画面の検証期間・評価サイクルは別の条件です。

### 画面と設定

- 起動時にダッシュボードを表示します。最後に開いた画面の復元は廃止しました。
- Windows 自体の時刻同期を設定画面に追加しました。必要な管理者承認を経て Windows Time サービスの同期を実行し、既存の時刻サーバー設定は変更しません。
- 初期状態の実画面 11 枚を含む[画像付き操作マニュアル](https://github.com/HatchSystem/anomaly-studio-oss/blob/main/docs/manual/README.md)と[印刷用 HTML](https://github.com/HatchSystem/anomaly-studio-oss/blob/main/docs/manual/index.html)を追加しました。画像は v0.1.0 の開発実行で撮影したものです。
- [導入マニュアル](INSTALL.md)に v0.2.0 の新規インストールと既存版からの更新手順を追記しました。

### 導入時の注意

更新前の設定・市場データを削除する必要はありません。アプリ内更新または同じ OS・CPU の Setup ファイルを使用し、起動後に `0.2.0` の版表示を確認してください。

Windows x64 のインストール・更新の仕組みは検証済みです。Windows ARM64 と Mac 2 種はビルドのみで、実機の動作・更新は未検証です。Windows は未署名、Mac は簡易署名のみです。市場データと経済指標は非公式の方法で取得します。将来の取引成績を保証するものではありません。

操作マニュアルの撮影時に、既存モードの編集ボタンから画面が切り替わらない挙動が確認されました。このリリースでの修正対象には含まれていません。詳細と撮影時の確認範囲は操作マニュアルに記載しています。
